# ArchMind 竞品分析

> 版本 v1.0 ｜ 2026-09-08 ｜ 依据公开资料整理（品茗/广联达/PKPM 官网、住建部信息中心、行业报道）

## 一、行业背景：为什么需要专业工具

建筑规范查询是设计从业者的高频刚需，但传统方式效率低：

- 行业报道显示，设计师查一条规范平均耗时 **8.6 分钟**，查规范时间约占出图周期的 **15%**（机电规范查询场景，2026-07 行业报道）
- 一次完整规范核查平均耗时 **2.5 小时**（设计院场景，2026-08 行业报道）
- 通用搜索存在"条文出处模糊、强制等级不明、废止标准混杂"的专业壁垒

## 三、市场空白

现有竞品分两类，都未覆盖的空白点：

1. **ToB 企业级"大而全"**（品茗/广联达/PKPM）：内置国标全集、走设计院采购，面向机构而非个人；只做"查条文/问答"，不做基于个人资料的**场景化分析输出**（汇报/论文/图注/策略）
2. **通用工具**（搜索/通用 AI）：无建筑专业上下文、回答不溯源、有编造条款风险

**ArchMind 定位**：面向**个人设计师与学生**的"**私有资料 + 溯源问答 + 场景化分析**"轻量工具——上传自己的规范摘录、文献与案例，即问即答且附来源，并按场景（课程汇报/论文分析/作品集图注/设计策略）模板化输出分析报告。

## 四、差异化要点

| 维度 | 竞品现状 | ArchMind |
|---|---|---|
| 客户形态 | 企业采购、重部署 | 个人直接用、上传即用 |
| 资料范围 | 内置公开国标 | 用户私有资料（规范摘录/文献/案例） |
| 回答形态 | 条文问答 | 问答 + 来源片段核验 |
| 输出能力 | 检索为主 | 场景化模板输出（汇报/论文/图注/策略） |
| 成本 | 企业级报价 | 免费公开 Demo |

## 五、风险与应对

- **大厂下沉**：品茗/广联达若推出个人版，将形成正面竞争 → 依靠"私有资料 + 场景分析"差异化，避免正面拼规范库规模
- **通用 AI 能力增强**：通用模型持续增强溯源能力 → 深耕建筑垂直场景的专业输出质量与模板化体验
- **资料合规**：用户上传资料的版权与合规边界需在文档中说明（仅用于个人学习研究）
